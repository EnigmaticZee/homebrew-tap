# Homebrew tap for Paws Off

[Paws Off](https://github.com/EnigmaticZee/PawsOff) pauses your keyboard with one click, so you can clean it, or step away without your cat writing your emails.

```sh
brew install --cask enigmaticzee/tap/paws-off
```

The cask always installs the latest release, and Paws Off keeps itself up to date after that.
